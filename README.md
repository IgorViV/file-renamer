# file-renamer

CLI-утилита для массового переименования дат в именах файлов, папок и целевых
путях ярлыков Windows: `ДД.ММ.ГГ` → `ГГГГ.ММ.ДД`.

## Возможности

- переименование файлов и папок с датой в префиксе имени;
- обновление целевых путей ярлыков `.lnk` без потери их свойств;
- предпросмотр плана, dry-run и подтверждение перед изменениями;
- защита от перезаписи существующих файлов и от удаления ярлыков при ошибке;
- журналирование всех изменений (`было -> стало`).

## Требования

- Python 3.9+;
- Windows — для работы с ярлыками (нужен `pywin32`);
- файлы и папки можно переименовывать и на других ОС.

## Установка и запуск

```bash
pip install .
file-renamer
```

Запуск без установки (из каталога проекта):

```bash
python file-renamer.py
```

Для работы с ярлыками нужен установленный `pywin32` (на Windows ставится
зависимостью пакета).

## Формат даты

- в имени должно быть `ДД.ММ.ГГ`, после даты — пробел;
- двузначный год: `69–99` → `1969–1999`, `00–68` → `2000–2068`;
- невалидные даты (`31.04.25`, `29.02.25`) не переименовываются и попадают
  в счётчик ошибок.

## Порядок работы

1. Сначала переименуйте файлы и папки.
2. Затем обновите ссылки в ярлыках.

Перед изменениями показывается план и запрашивается подтверждение. Ярлыки
обновляются на месте; при отсутствии новой цели ярлык остаётся нетронутым.

## Тесты

```bash
python -m unittest discover -s tests -t . -v
```

Тесты не требуют Windows и `pywin32`: COM-вызовы подменяются, а импорты
Windows-зависимостей выполняются лениво.
