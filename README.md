# file-renamer

TUI-утилита для массового переименования дат в именах файлов, папок и целевых
путях ярлыков Windows: `ДД.ММ.ГГ` → `ГГГГ.ММ.ДД`.

Интерфейс построен на [ratatui](https://ratatui.rs) и crossterm.

## Возможности

- переименование файлов и папок с датой в префиксе имени;
- обновление целевых путей ярлыков `.lnk` через `IShellLinkW` без потери
  остальных свойств ярлыка (Windows);
- экран предпросмотра с прокруткой, ошибками и переключением dry-run;
- защита от перезаписи существующих файлов и от удаления ярлыков при ошибке;
- журналирование всех изменений (`было -> стало`);
- ротация логов и ограничение количества хранимых файлов.

## Требования

- Rust 1.88+;
- интерактивный терминал для TUI;
- Windows — для работы с ярлыками (COM API `IShellLinkW`);
- файлы и папки можно переименовывать на любой ОС.

## Сборка и запуск

```bash
cargo run --release
```

Или после сборки:

```bash
cargo build --release
./target/release/file-renamer
```

Справка и версия без запуска TUI:

```bash
cargo run -- --help
cargo run -- --version
```

## Управление

| Клавиша | Действие |
|---|---|
| `↑` / `↓` | навигация по меню и прокрутка плана |
| `Enter` | выбрать пункт / применить план |
| `Esc` | вернуться назад |
| `d` | включить или выключить dry-run |
| `Ctrl+C` | выход |

Основной сценарий:

1. Выберите «Переименование файлов и папок».
2. Введите путь к каталогу и нажмите `Enter`.
3. Проверьте план на экране предпросмотра.
4. Нажмите `Enter`, чтобы применить, или `d` для dry-run.
5. Затем обновите ярлыки отдельным пунктом меню.

Файлы и папки обрабатываются от самых глубоких. Символические ссылки при
обходе пропускаются. Перед изменениями всегда показывается план.

## Формат даты

- в имени должно быть `ДД.ММ.ГГ`, после даты — пробел;
- двузначный год: `69–99` → `1969–1999`, `00–68` → `2000–2068`;
- невалидные даты (`31.04.25`, `29.02.25`) не переименовываются и попадают
  в счётчик ошибок.

## Логи

- Windows: `%LOCALAPPDATA%\file-renamer\logs`;
- Linux/macOS: `$XDG_STATE_HOME/file-renamer/logs` или
  `~/.local/state/file-renamer/logs`;
- свой каталог задаётся переменной `FILE_RENAMER_LOG_DIR`.

На каждый запуск создаётся отдельный файл, включена ротация (1 МБ, 3 архивные
копии), хранятся 10 последних файлов. Время в логах — UTC. Если каталог
недоступен, логи выводятся только в консоль с предупреждением.

## Тестовые данные

Для ручной проверки можно сгенерировать каталоги и файлы (отдельный
консольный бинарник, не TUI):

```bash
cargo run --bin create-test-data -- \
  --dir temp_dir --depth 3 --seed 1 --yes --force
```

На Windows дополнительно создаются ярлыки `.lnk`; флаг `--no-shortcuts`
отключает их.

## Тесты и проверки

```bash
cargo test
cargo clippy --all-targets -- -D warnings
cargo fmt --check
```

TUI тестируется через `ratatui::backend::TestBackend`, включая рендеринг
меню, ввод пути, предпросмотр, dry-run и применение плана.

Windows-код проверяется кросс-компиляцией:

```bash
rustup target add x86_64-pc-windows-msvc
cargo check --target x86_64-pc-windows-msvc --all-targets
```

## Структура

- `src/date.rs` — разбор и проверка дат;
- `src/paths.rs` — преобразование дат в компонентах путей;
- `src/logging.rs` — журнал с ротацией;
- `src/renamer.rs` — поиск, план и переименование;
- `src/shortcut.rs` — абстракция ярлыков и Windows COM-бэкенд;
- `src/tui.rs` — интерфейс ratatui и тесты TUI;
- `src/main.rs` — точка входа;
- `src/test_data.rs`, `src/bin/create-test-data.rs` — генератор тестовых данных.
